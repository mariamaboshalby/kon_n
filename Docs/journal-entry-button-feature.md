# ميزة زر عرض القيد المحاسبي ✅

## نظرة عامة
تم إضافة زر جديد في صفحة السندات (Vouchers) لعرض القيد المحاسبي لكل سند بشكل تفصيلي ومنظم.

---

## 📍 الموقع
**الصفحة:** `http://127.0.0.1:8080/vouchers`  
**الملف:** `resources/views/vouchers/index.blade.php`

---

## ✨ الميزات

### 1. زر عرض القيد المحاسبي
- **الموقع:** عمود الإجراءات (Actions) في جدول السندات
- **الأيقونة:** <i class="fas fa-book"></i> (كتاب)
- **اللون:** أزرق (Primary)
- **الوظيفة:** فتح نافذة منبثقة (Modal) تعرض تفاصيل القيد المحاسبي

### 2. نافذة القيد المحاسبي (Modal)
تحتوي على:

#### أ. معلومات السند
- تاريخ السند
- نوع العملية (مع Badge ملون)
- المبلغ
- المستخدم
- الوصف

#### ب. جدول القيد المحاسبي
- **العمود الأول:** اسم الحساب (مع رقم الحساب)
- **العمود الثاني:** المدين (Debit) - باللون الأخضر
- **العمود الثالث:** الدائن (Credit) - باللون الأحمر

#### ج. الإجماليات
- إجمالي المدين
- إجمالي الدائن
- حالة التوازن:
  - ✅ **متوازن** (إذا كان المدين = الدائن)
  - ⚠️ **غير متوازن** (مع عرض الفرق)

#### د. الملاحظات
- عرض ملاحظات السند (إن وجدت)

### 3. زر الطباعة
- **الوظيفة:** طباعة القيد المحاسبي في نافذة جديدة
- **التنسيق:** تنسيق احترافي جاهز للطباعة
- **المحتوى:**
  - رأس الصفحة مع عنوان القيد
  - جميع تفاصيل السند
  - جدول القيد المحاسبي
  - الملاحظات

## 🎨 التصميم

### الألوان المستخدمة:
- **الزر الرئيسي:** أزرق (btn-primary)
- **رأس النافذة:** أزرق داكن (bg-primary)
- **المدين:** أخضر (text-success)
- **الدائن:** أحمر (text-danger)
- **Badge نوع السند:**
  - سند قبض: أخضر (bg-success)
  - سند صرف: أحمر (bg-danger)
  - سند مصروفات: برتقالي (bg-warning)
  - سند قبض متعدد: أزرق (bg-primary)
  - سند صرف متعدد: سماوي (bg-info)

### الأيقونات:
- 📖 `fa-book` - زر عرض القيد
- ✅ `fa-check-circle` - قيد متوازن
- ⚠️ `fa-exclamation-triangle` - قيد غير متوازن
- 🖨️ `fa-print` - زر الطباعة
- ❌ `fa-times` - زر الإغلاق
- 📝 `fa-sticky-note` - الملاحظات

## 🔧 كيفية الاستخدام

### للمستخدم:
1. افتح صفحة السندات: `http://127.0.0.1:8080/vouchers`
2. ابحث عن السند المطلوب في الجدول
3. اضغط على زر **📖** (الأزرق) في عمود الإجراءات
4. ستظهر نافذة منبثقة تعرض القيد المحاسبي
5. يمكنك طباعة القيد بالضغط على زر "طباعة"

### للمطور:
```blade
{{-- الزر في الجدول --}}
<button type="button" 
        class="btn btn-sm btn-primary" 
        data-bs-toggle="modal" 
        data-bs-target="#journalEntryModal{{ $voucher->id }}"
        title="{{ __('View Journal Entry') }}">
    <i class="fas fa-book"></i>
</button>

{{-- النافذة المنبثقة --}}
<div class="modal fade" id="journalEntryModal{{ $voucher->id }}" ...>
    <!-- محتوى النافذة -->
</div>
```

## 📊 منطق القيد المحاسبي

### سند القبض (Receipt - Type 1):
```
من حـ/ الصندوق/البنك (account1)     [مدين]
    إلى حـ/ العميل/الحساب (account2)  [دائن]
```

### سند الصرف (Payment - Type 2, 3, 101):
```
من حـ/ المورد/المصروف (account2)     [مدين]
    إلى حـ/ الصندوق/البنك (account1)  [دائن]
```

### السندات المتعددة (Multi - Type 32, 33):
```
يتم عرض الحسابات كما هي مخزنة في قاعدة البيانات
```
