# ميزة تحديد الصلاحيات الجماعي (Select All Permissions)

## نظرة عامة
تم إضافة ميزة جديدة لتسهيل إدارة صلاحيات المستخدمين في صفحات إنشاء وتعديل المستخدمين.

## الميزات المضافة

### 1. تحديد جميع الصلاحيات (Master Select All)
- موقع الزر: أعلى يمين قسم الصلاحيات
- الوظيفة: يحدد/يلغي تحديد جميع الصلاحيات في جميع الفئات دفعة واحدة
- اللون: أخضر للتمييز
- الأيقونة: `fa-check-double`

### 2. تحديد الكل لكل فئة (Category Select All)
- موقع الزر: أعلى يمين كل جدول فئة
- الوظيفة: يحدد/يلغي تحديد جميع الصلاحيات في الفئة الحالية فقط
- موجود مسبقاً وتم الحفاظ عليه

### 3. تحديد الكل لكل عمود (Column Select All) - جديد
- الموقع: في رأس كل عمود (View, Create, Edit, Delete, Print)
- الوظيفة: يحدد/يلغي تحديد جميع الصلاحيات في العمود المحدد ضمن الفئة الحالية
- مثال: الضغط على checkbox في عمود "View" يحدد جميع صلاحيات العرض في تلك الفئة

## التحسينات على الواجهة

### CSS Enhancements
- إضافة `vertical-align: middle` لرؤوس الجداول
- تأثير hover على checkboxes الأعمدة (تكبير + تغيير لون الحدود)
- تمييز checkbox "تحديد الكل الرئيسي" بلون أخضر عند التحديد
- تحسين المسافات والتباعد

### JavaScript Functionality
```javascript
// 1. Select All for Category (موجود مسبقاً)
document.querySelectorAll('.select-cat-all').forEach(...)

// 2. Select All for Column (جديد)
document.querySelectorAll('.select-column-all').forEach(...)

// 3. Master Select All (جديد)
document.getElementById('selectAllPermissions').addEventListener(...)
```

## كيفية الاستخدام

### سيناريو 1: تحديد جميع الصلاحيات
1. انتقل إلى قسم "Permissions"
2. اضغط على "تحديد جميع الصلاحيات" في الأعلى
3. سيتم تحديد جميع الصلاحيات في جميع الفئات

### سيناريو 2: تحديد صلاحيات فئة معينة
1. انتقل إلى الفئة المطلوبة (مثل: Inventory)
2. اضغط على "تحديد الكل في Inventory"
3. سيتم تحديد جميع صلاحيات هذه الفئة فقط

### سيناريو 3: تحديد صلاحيات عمود معين
1. انتقل إلى الفئة المطلوبة
2. اضغط على checkbox في رأس العمود المطلوب (مثل: View)
3. سيتم تحديد جميع صلاحيات العرض في هذه الفئة

### سيناريو 4: تحديد مخصص
1. استخدم أي من الطرق أعلاه كنقطة بداية
2. قم بإلغاء تحديد الصلاحيات غير المرغوبة يدوياً

## الفوائد

1. **توفير الوقت**: تقليل الوقت المستغرق في تحديد الصلاحيات من دقائق إلى ثوانٍ
2. **تقليل الأخطاء**: تجنب نسيان تحديد صلاحيات معينة
3. **مرونة أكبر**: خيارات متعددة للتحديد حسب الحاجة
4. **تجربة مستخدم أفضل**: واجهة أكثر سهولة وبديهية

## الاختبار

### اختبارات يدوية مقترحة:
1. ✅ تحديد جميع الصلاحيات والتأكد من تحديدها جميعاً
2. ✅ إلغاء تحديد جميع الصلاحيات والتأكد من إلغائها جميعاً
3. ✅ تحديد صلاحيات فئة واحدة فقط
4. ✅ تحديد عمود واحد في فئة معينة
5. ✅ التبديل بين الفئات والتأكد من عمل الـ checkboxes بشكل صحيح
6. ✅ حفظ المستخدم والتأكد من حفظ الصلاحيات المحددة
7. ✅ تعديل مستخدم موجود والتأكد من عرض الصلاحيات الحالية

## ملاحظات تقنية

### Data Attributes المستخدمة:
- `data-column`: نوع الصلاحية (view, create, edit, delete, print)
- `data-category`: slug الفئة (مثل: inventory, sales)
- `data-target`: selector للعناصر المستهدفة

### Classes المستخدمة:
- `.select-cat-all`: checkbox تحديد الفئة
- `.select-column-all`: checkbox تحديد العمود
- `.perm-checkbox`: checkbox الصلاحية الفردية
- `.group-{category}`: مجموعة صلاحيات الفئة

## الصيانة المستقبلية

عند إضافة أعمدة صلاحيات جديدة:
1. أضف العمود في رأس الجدول مع checkbox
2. أضف `data-column` attribute للـ checkboxes الفردية
3. أضف الترجمة في `lang/ar/permissions.php`
4. لا حاجة لتعديل JavaScript (يعمل تلقائياً)
